## MES 형식 (확정분)
- 머리: u16 **LE** n(**길이 칸 2바이트 포함**, 본문 시작 = n) + SJIS u16 글자표(최대 128자)
- 본문 바이트:
  - `0x80–0xFF` → 글자표[b−0x80] (1바이트 글자)
  - `0x61–0x7F` + 1바이트 → **SJIS − 0x2000** (첫 바이트+0x20). 修=6F43, び=62D1 등 8곳 검산
  - `0x00–0x3F` → 스크립트 토큰(0x03 문장 끝, 0x02 인수 구분, 0x01/0x00 블록 시작/끝, 0x0F if, 0x12 라벨, 0x04 내장 함수, 0x06…0x06 파일명 문자열)
  - `％` = 줄바꿈, 대사 = `13 3C 03 … 13 3E 03` 또는 `13 07 73 03 이름％「…」13 3E 03`
  - 선택지 `04 13 01 항목<02>항목<00>`, 아이템 이름 = RESET.MES `02 0F i N 27 03 01 이름 00` (if 블록)
- ✅**길이 바꿔도 됨(2026-10-30 확정)** — 파일 안에 오프셋 없음. 라벨 표 0x060684C0 은 명령 0x12 처리기(0x06007054)가 실행 중 «표[번호]=현재 위치»로 채움, 호출 0x13 은 번호로 찾음
- ⚠️**MES 한 파일 ≤ 0x10000 B** — 적재 0x060B0000(초기화 0x060042E4), 0x060C0000 부터 다른 버퍼(포인터 0x0603720C). 가장 빠듯 = SIRO1A1(여유 3,555 B, 대사 바이트 +37% 까지)
- ⚠️**블록 건너뛰기(0x06008954)는 바이트 01/00 만 센다** → 번역문 바이트에 00·01 금지(우리 인코딩은 ≥0x61 이라 안전, 빌더에서 검사)
